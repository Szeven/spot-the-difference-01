Lighthouse Cove is an original spot-the-difference game: two hand-drawn scenes side by side, three illustrated levels (a lighthouse cove, a mushroom hollow and a starlight camp), clickable differences with golden rings, a countdown timer, hints, combos, keyboard and mouse play, and WebAudio sounds — all offline, no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and play. Or serve `game/` with any static HTTP server and open `game/index.html`.
